# Security Policy

## Reporting a vulnerability

Please do not open a public issue or pull request for a security vulnerability.

- **Bug bounty:** submit through the [Lista DAO bug bounty on Immunefi](https://immunefi.com/bug-bounty/listadao/information/). Rewards, scope and rules are listed there.
- **Security contact:** email lawson.c@lista.org for anything outside the bounty, or to reach the maintainers directly.

Please include the affected contract and commit, the impact, and a proof of concept (a Foundry test is ideal).

## Scope

The contracts under `src/`, deployed as Lista Lending on BNB Smart Chain and Ethereum. Code under `lib/`, `test/` and `script/` is out of scope. Findings already reported in the published audits are not eligible for a reward.
